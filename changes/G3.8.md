# G3.8: CI integration: OIDC exchange, attest workflow, post-land CI

- `graft-auth::oidc`: exchanges a GitHub Actions OIDC token, or a Woodpecker job token, for a short graft token (kind `ci`, at most 15 minutes and never past the CI token's expiry). It verifies the JWT against the issuer's JWKS (`RS256` and `EdDSA` only, `kid` required, RSA of at least 2048 bits), then `iss`, `aud`, `exp`, `nbf`/`iat` and lifetime. A `Binding` maps a CI repository to a graft repository and its scopes (`read`/`write` only), and can require the repository id, refs and the pinned reusable workflow. A valid token for any other repository is refused. Tests use recorded JWKS and tokens generated with throwaway keys (`tests/fixtures/oidc/gen.py`).
- `ci/`: a reusable pre-land workflow (checks on `graft/*` branches, then `Attest`), a post-land workflow for the mirror's pushes, and callers. They expect `graft ci exchange` and `graft attest` commands that `graft-cli` does not have yet; see `ci/README.md`. The live rehearsal is a follow-up.
