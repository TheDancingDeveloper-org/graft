- `deploy/onboard-repo.sh OWNER/REPO BASE [LINE]` performs language-agnostic,
  idempotent graft-dev onboarding in one command: declare and deploy a mirror,
  wait for its first imported ref, create the integration line, and store a
  narrow `read`/`write`/`drafts`/`land` issuer token in Infisical for Vogt's
  per-session agent tokens. `--dry-run` prints the plan and D28 ruleset.
