bench/postland records the v0.2 exit measurements. record.py follows a line from a stored LSN through `graft api watch` and `GET /v1/repos/{repo}/land-checks` (token in a header, never argv), re-reads every still-pending land each poll, and writes JSONL. Late means observed more than `--late-after` seconds (default 120) after the journaled time; a body with no journal time is not late. plant.py lands a fmt or test plant and a good follower and prints both changeset ids. report.py writes the M1 table (p95 ≤ 30 min, max ≤ 4 h, precision bounded by `--interval`, Blocked as n/a unless an attester report is journaled), the M2 plant table, the M3 day table and the D31 table from the Prometheus HTTP API. Tests replay captured graft-dev responses.
