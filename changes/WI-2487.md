# WI-2487: GitHub credential for every graft-dev mirror

- `up.sh` fetches `HOMELAB_VOGT_GITHUB_TOKEN` at deploy time and writes
  `/etc/graft/github-token` mode 0600. The value never goes on argv, in logs,
  or in compose env.
- Every mirror mounts that file at `/run/secrets/github-token` and sets
  `[github] token_file` so `pr-batch` can push `graft/batch-*` for public
  repos too.
- `deploy/tests/onboard-render.sh` treats a successful `docker run` as exit 0
  (the inverted-rc leftover from #229) and covers 75-then-1.
