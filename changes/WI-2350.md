- CLI: `commit` and the MCP commit tool record `VOGT_SESSION_ID` and `VOGT_WORK_ITEM` as `vogt.session` and `vogt.work_item` draft metadata (an explicit `--meta` wins), so lands and `pr-batch` show the session and work item. The call context carries them too, with principal kind `agent` when a session is set. The default author is `GRAFT_AUTHOR_NAME`/`_EMAIL`, else the git author identity (`GIT_AUTHOR_*`, else git's `user.name`/`user.email`), else `$USER`; the default author kind is `agent` inside a Vogt session. No format change (WI-2350).
