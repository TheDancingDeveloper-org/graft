- graft-engine, graft-mirror: a repository that was just created and bound to a mirror now imports with the `mirror` token alone. For a line its row follows that does not exist yet, the mirror may upload objects, import changesets and create the followed-line marker, then the line, all under its lease. It still cannot touch a line that exists without a marker, a line its row does not follow, or a repository with no enabled row. Before, the first upload was refused (`needs repo:<name>:write`) and the repository never imported.
- graft-mirror: a followed line created by an earlier import with a different database is adopted when re-importing the upstream history reproduces its tip, instead of stopping the line as `graft-moved`.
