# WI-2452 — MCP registration without flags

`graft mcp` inside a working copy already resolves the named server and
token from the working copy and the user config (WI-2450). Registration
snippets for Claude Code, Codex and Cursor are in `docs/agents.md`, linked
from the README. None of them store a token.

A `graft mcp --print-config` helper was not added: `graft-cli` is owned by
another item. The snippets are static and name no secret.
