- graft-cli: `graft mcp` runs the graft MCP server over stdio against the remote API, with the same endpoint and token discovery as every command (`--endpoint`, `GRAFT_ENDPOINT`, the working copy's server; `--token-file` or `GRAFT_TOKEN`). Inside a working copy it serves the working-copy tools: `graft_status`, `graft_commit` with `from_working_copy`, and `graft_land` and `graft_sync` on the working copy's workspace, which move the working copy too. `mcp` is no longer a planned command.
- graft-mcp: an additive `WorkingCopyTools` hook and `McpServer::with_working_copy`, through which the stdio host serves a working copy.
