- graft-index: documents the tie-break rule for identical lines in `blame`. Histogram diff matches a repeated line to one of its copies, so graft and git blame can name different commits for the same line. Both are valid. The rule is in the module docs.
- graft-testkit: the pilot's blame agreement check accepts an equivalent tie-break: each origin is on the file's first-parent history, its diff (Myers or histogram) adds the line's content, and that content is present in every first-parent version from the origin to the tip. A line deleted and re-added belongs to the re-adding commit; a line from a merge's second parent belongs to the merge. A wrong origin still fails. The report counts these as `equivalent tie-breaks`.
