# G2.7: engine file-level rebase and Sync

- `graft-engine`: `Rebase` implements the file-level table in design §7.8. For each changed path it compares the draft's base, the target and the draft by entry kind and id, so mode and symlink changes count as changes. A path the target already has is dropped, and a divergent path conflicts. A file/directory clash is always a conflict, whether the entries differ or applying the kept changes would make a path both a file and a directory. A stack rebases bottom-up: the walk runs from the given head down to the first landed changeset (or `onto`), bounded by `max_stack`. The whole stack is planned in memory before anything is written, so a conflict creates nothing. A draft whose changes are all already on the target disappears; when every draft disappears, the result is `onto`. Rebased changesets keep author, time, message and metadata, and add `graft.rebased-from`. They are deterministic, so a repeated rebase returns the same id. A rebase onto an unchanged base returns the drafts unchanged. Results are stored abandoned until a workspace adopts them. The caller needs write on every path the stack changes. `merge = line` is answered at file level until G3.7.
- `graft-engine`: `Sync(workspace, onto?)` rebases the stack onto the line tip (or `onto`, which must be on the workspace's line). One CAS on the workspace then adopts the new drafts, supersedes the old ones (each by its successor; a draft that disappeared is superseded by the draft below it, or by the target) and moves the base and head. It writes a `WorkspaceSynced` journal entry. A lost CAS (a racing `SetHead` or renewal) re-reads and retries. It returns the paths that differ between the old top and the new one, capped by the new `EngineConfig::max_sync_paths`. A sync needs the workspace's owner or a repository admin, a live lease, and write on the stack's paths.
- Cost follows the change: tree reads on each changed path plus one changeset read per draft. Tests count reads and show they do not depend on the distance to the target.
