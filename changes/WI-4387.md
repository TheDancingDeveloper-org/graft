An oversight-only token kind can bind a mirror, and `/mcp` carries the mirror
tools. `MintToken` gains an optional `kind`, and only an oversight-kind caller
may mint an oversight token; a worker asking for one is refused, and a token
minted for another subject is still an `Agent`, so a worker never holds
`mirror:bind`. `mirror:bind` and `mirror:export` stay bounded by
`mirror.allowed_hosts`.

The server's own `/mcp` mount now installs the in-process mirror service, so
`graft_mirror_add|set|credential|status|list|remove|purge` and
`graft_batch_cut|status|cancel|list` work there as they do in `graft mcp`.
`graft_mirror_add|set` take `start_at`. `graft_mirror_credential` reads the
value from a file on the MCP server host and never puts it in a tool argument,
result or log.
