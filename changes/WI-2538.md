# WI-2538: graft doctor checks config, server, endpoint, protocol and token

`graft doctor` prints `ok`, `fail` or `skip` for the user config, the resolved server, one unauthenticated default-line read, protocol compatibility, and a peeked token (expiry and scopes only). `--json` prints `{checks: [{name, ok, detail}]}`. The exit is 0 only when every check passes. The token is never printed.
