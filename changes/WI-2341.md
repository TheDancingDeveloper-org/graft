- Read paths (WI-2341): `log`, `show`, `blame`, `cat`, `ls` and the other read commands no longer parse the working-copy index (`WorkingCopy::open_info`). The index parser is about 2x faster. Opening the client object cache no longer stats every cached object: LRU counters are saved to `.usage` and the walk is deferred to the first eviction. The server keeps a bounded cache of decoded changesets for log pages. Bench at 1k on a loaded host: log -50 3.4 -> 2.4 ms, sync (5 behind) 17.2 -> 13.5 ms, status unchanged within noise. Floors: sync fsyncs `.graft/index` and `.graft/state` (7-9 ms; git does not fsync its index); status is bounded by one lstat per file plus a directory walk. 10k before/after numbers on graft-dev are pending.
